## Summary

Commit C of customer-creation-on-ingest: (1) make the existing AddToCustomersDialog the
primary action on unlinked threads in both inbox views, stamping `created_via='inbox_assisted'`
and bulk-linking the handle's conversations; (2) a one-off 2-phase (dry-run/execute) edge
function backfills Sears Melvin's email-shaped unlinked conversations through the **live**
`attemptAutoLink`/`shouldAutoCreatePerson` code path; (3) fix the Change-link dead button by
deleting its circular `canLink` gate; (4) enforce the `created_via` vocabulary with a CHECK
constraint after stamping the two unstamped frontend writers (`createCustomer` entry points,
`resolvePersonId`). All spec open questions ruled 14 Aug (OQ-1 marker deferred; OQ-2 edge
function) — see research.md.
